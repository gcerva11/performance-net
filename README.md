# PerformanceNet

A Java application designed to track and analyze cross country and track performance data.

## Features
- Store and manage athlete performance data using file-based storage
- View, edit, and analyze results
- Simulate hypothetical performance outcomes to improve team scoring

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Arrays and ArrayLists
- File I/O

## How It Works
- Reads athlete data from text files
- Processes and organizes results by event
- Allows users to analyze and simulate performance scenarios

## How to Run
1. Compile the project
2. Run `Main.java`
3. Follow prompts in the console

## Status
Used by Modesto High School coaches for two competitive seasons
